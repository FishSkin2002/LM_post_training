1. 标题使用“大语言模型数学推理后训练”，描述项目用途，不展示个人背景。

## 每个用途的命令格式

- 每个用途给一条示例指令；该用途必需的参数和值直接写入示例，路径占位符说明如何替换。
- 示例下方列出该用途可用的可选参数，说明可填项、默认行为和用途。用途已经选定的互斥来源参数不再列为其他可选来源。
- 同一参数在不同用途中的作用分别就近说明；不让用户跨多个段落拼接命令。
- 参数是否必填、互斥关系、默认值与可填项以实际脚本为准。用途需要覆盖默认行为时，可在示例中显式设置相应参数。
- TensorBoard 等配套命令单独成组，沿用“用途 → 示例 → 可选项”的组织方式。
